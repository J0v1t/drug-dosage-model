Model & Sources

Oral absorption into one well-mixed systemic compartment, with first-order absorption and elimination. The body tint represents one systemic concentration; it does not predict separate organ concentrations.

The equations

dG/dt = −kₐG
dA/dt = FkₐG − kₑA
C = A/V
kₑ = ln(2)/t½

G is the drug amount in the gut (mg), A is systemic amount (mg), F is bioavailability, V is distribution volume (L), and C is concentration (mg/L). Doses enter G. The simulation starts with no drug in the body. Doses are administered strictly before the selected end time.

Reading the results

Python numerically integrates the equations. Peaks are located from the numerical solution between doses. The latest trough is the concentration immediately before the latest subsequent dose within the simulation; it is not necessarily a steady-state trough. Exposure is AUC over the displayed period (mg·h/L). The absorption pulse follows input from the gut. Rose tint intensity follows systemic concentration using the same scale in every scenario.
